Monthly Target

Set once per month by the factory owner. Day and week targets below are derived from this automatically and re-balance to catch up or ease off based on actual output - no manual daily entry needed.

Ideal Speed - Monthly

Set once per month (machine capability, in m/min) and used for the Performance figure in OEE on every day of that month. You can change it any time - the whole month recalculates. If a month has no value yet, the most recent earlier month's value carries over.

Daily Target vs Actual -

Target re-balances daily based on how the month is actually going. Dashed line is a forecast for the rest of the month based on the last 7 days' average.

Weekly Rollup -

Same daily targets grouped into 7-day blocks.

Yearly Achievement -

Cumulative actual vs cumulative target across the year. Months with no monthly target set show as a flat line (nothing to compare against).

Attendance

Present = at least one punch session that day. There's no leave-tracking data source yet, so Leave Days shows 0 and Absent covers every non-present day - see the note below.
No separate Leave record exists in the system yet - every day without a punch session counts as Absent. If you want approved leave excluded from Absent, that needs a new Leave entry (happy to add it).

Production
